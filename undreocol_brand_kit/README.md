# UndreoCol Brand Kit
Paquete inicial para web, PWA y sistema.
- logo/: SVG maestro y wordmarks
- icons/app/: iconos PWA
- icons/favicon/: favicons
- splash/: pantallas de carga
- system-icons/: sprite SVG
- web/: manifest y tokens CSS
- docs/: guía rápida

El símbolo conserva la U y la flecha del logo suministrado, con geometría limpia y grosor uniforme. SVG es la fuente maestra.
